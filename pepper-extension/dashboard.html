    Features

    Learning, site by site

    With learning on, Pepper saves each prompt you send on that site, up to 4,000 characters of the reply, and your star rating, to learn which approach works for you. With it off, Pepper still writes prompts there but saves nothing.

    AI

    Alt+Shift+P opens Pepper on any page.

    Your data

    Everything Pepper keeps stays in this browser. If you add a model key, the text Pepper needs goes to that provider when you ask it to write, rewrite or find facts. Nothing else leaves. Privacy notice

    Export everything

    A JSON file of your profile, details, memories, projects, Pocket list, history and what Pepper learned. Your API key and file contents are not included.
