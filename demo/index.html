Type a few words.
Get the prompt you meant.

Pepper — The Personal AI Prompter rewrites a rough request into a six-part prompt (Role, Context, Task, Constraints, Output format, Success criteria) using only what you've told it about yourself, then puts it in the chat box of ChatGPT, Claude, Gemini, Perplexity or Copilot. You read it and press send. Pepper never sends anything for you.

Try it below Watch the 2-minute demo

Everything on this page runs Pepper's real prompt engine (lib/core.js, the same file the extension ships) in your browser. Nothing you type leaves this page.

02 · Safety

Pepper only says what you've confirmed

A model will happily guess facts about you. Pepper asks it to list those guesses after a marker, splits them off, and keeps them out of the prompt until you say they're true.
